Windows Edgeを用いた実ブラウザテストです。GitHub ActionsはChromiumで同じ19件と単体・文書検査を実行します。撮影テストは写真を更新するときだけ実行し、CIで既存写真を書き換えません。

公開前のCI #2では、ガイド終了直後のスクロール等でキーボードのツールチップが消え、1件が失敗しました。フォーカス中は説明を保持し、離れた要素のイベントでは消さないよう修正しています。単にテストを省略せず、マウス移動とスクロール後の表示も検査へ追加しました。

公開画面でPC幅からスマホ幅へ変更した際、ガイドの操作箇所が画面外に残る状態を発見しました。サイズ変更時も対象へスクロールし、スマホでは対象を画面上側へ置くよう修正しています。サイズ変更への追従と、全5段階で説明カードが強調枠を隠さないことも自動テストへ追加しました。

サイズ・スクロール通知が同時に届くと移動予約が取り消される条件も修正し、移動の必要を次の描画まで保持します。テストはPC幅の描画を2フレーム待ってからスマホ幅へ戻し、途中の状態も通過させています。
