## 調査結果と採用方針

| 項目 | 元アプリ | SYNTHIA v1 |
| --- | --- | --- |
| 歌詞抽出 | `extractLyrics`でtrim・角括弧メタ行などを除外、配列へ反映 | 空白を保持し、指定Sunoタグだけをセクション化。数字や未認識タグは歌詞として保持 |
| R | 入力中の別行が未終了なら閉じ、現在行開始、次行選択。開始以下の終了を自動クリア | 行送りと未終了行の連続終了を保持。逆転時は操作を拒否して終了を保護 |
| E | 最後にRで開始した行、または現在行を終了 | 両モードを保持 |
| W | 通常タップオフセット＋W追加補正を加算 | 同じ加算意味で保持 |
| Shift＋R/W | 前行終了と現在行開始を揃え、入力中行を解除、次行へ | 同じ境界編集。終了は保持。逆転・ロックは原子的に拒否 |
| Shift＋E | v1.64でEモードを一時反転 | 両方向の反転を保持・テスト |
| 時刻捕捉 | v1.63.1でUndoシリアライズ前に音源時刻を取得 | ハンドラ先頭で取得し整数ms化 |
| 波形 | Web Audioでデコード、800〜30000ピーク、サンプル間引き、周辺表示 | 最大16000ピーク、負荷上限、非同期中断、WeakMapキャッシュ、ズームとループ選択 |
| SRT読込 | 長／短時刻、ドット／カンマ、未完成記号、空行なしにも対応。本文trim | 形式互換を維持し、本文の空白を保持。破損ブロックは読み込み全体を拒否 |
| Undo | JSONスナップショット50回、Redoなし | 原子的スナップショット100回＋Redo |
| SRT出力 | 未完成独自記号を使う途中保存も可能 | 通常出力は標準SRTのみ。不完全な作業はJSONへ保存 |
| 重複 | v1.64.2で表示ミリ秒へ丸めて隣接比較 | 全内部値を整数msへ統一。非隣接重複も検出 |
| JSON | schemaVersion、字幕、選択、設定、音源名など。音源非埋込 | 独立schemaVersion、UUID、設定、原文・セクションを保存。復元位置を音源再選択時に使用 |
